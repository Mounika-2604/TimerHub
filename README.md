# ⏳ TimeTick - Countdown Timer

## Overview

TimeTick is a simple and responsive Countdown Timer built using HTML, CSS, and JavaScript. Users can enter the desired time in minutes and control the countdown using Start, Pause, Resume, and Reset buttons.

The project demonstrates DOM manipulation, event handling, timers, and responsive UI design using vanilla JavaScript.

---

## Features

* Enter countdown time in minutes
* Start countdown timer
* Pause timer at any time
* Resume paused timer
* Reset timer instantly
* Responsive and modern user interface
* Digital clock format (MM:SS)

## How It Works

1. Enter the number of minutes.
2. Click **Start** to begin the countdown.
3. Click **Pause** to temporarily stop the timer.
4. Click **Resume** to continue from the paused time.
5. Click **Reset** to clear the timer and start over.
